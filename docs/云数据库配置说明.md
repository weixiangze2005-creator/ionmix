# Ionmix 云数据库配置说明

网站账号和历史配方支持两种存储方式：

1. 没有配置数据库连接串时，使用本地 SQLite：适合本地开发和短期演示。
2. 配置 PostgreSQL 连接串后，自动使用云数据库：适合线上长期保存。

## 推荐方案

优先用 Supabase 或 Neon 的 PostgreSQL 免费项目。Render 免费 Web Service 的本地文件系统不是持久存储，重新部署或重启后 SQLite 文件可能丢失。

## Render 环境变量

在 Render 的服务页面进入：

`Environment` → `Add Environment Variable`

添加下面任意一个变量名即可，推荐第一个：

```text
IONMIX_DATABASE_URL=postgresql://用户名:密码@主机:端口/数据库?sslmode=require
```

也兼容：

```text
DATABASE_URL=...
SUPABASE_DB_URL=...
```

保存后重新部署。部署成功后访问：

```text
https://你的域名/api/model-info
```

如果看到：

```json
"account_storage": {
  "backend": "postgresql",
  "persistent": true
}
```

就说明已经接上云数据库。

## Supabase 注意

如果用 Supabase，建议从项目 Dashboard 的 `Connect` 里复制 Pooler 连接串。Render 这类云服务通常使用 IPv4 网络，Supabase 的 pooler 连接更稳。连接串里要把 `[YOUR-PASSWORD]` 替换成你的数据库密码。

## Neon 注意

如果用 Neon，可以从项目 Dashboard 点击 `Connect`，复制 PostgreSQL connection string。用于 Web 服务时建议使用 pooled connection string，并确认连接串带有 `sslmode=require`。

## 数据表

不需要手动建表。网站启动时会自动创建：

- `users`
- `sessions`
- `saved_formulations`

## 安全提醒

数据库连接串不要写进代码或 GitHub，只放在 Render 的 Environment Variables 里。
